# NidoReserva

Aplicación web de gestión de reservas de alojamiento, desarrollada como proyecto técnico con PHP nativo, MySQL/MariaDB, Twig y JavaScript.

## Funcionalidades

- Listado de reservas con filtros combinables.
- Consulta del detalle y del historial de eventos.
- Creación de reservas con validación de datos.
- Confirmación y cancelación de reservas.
- Interfaz web con actualizaciones mediante JavaScript sin recargar la página.

## Tecnologías

- PHP nativo, sin framework.
- MySQL/MariaDB y PDO.
- Twig para renderizar las vistas.
- JavaScript, HTML y CSS.
- Composer para gestionar dependencias y autoload.
